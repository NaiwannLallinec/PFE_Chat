# 🚀 **README : Comment Allumer Ton PC et Surfer sur le Web comme un Pro** 🌐

Bienvenue dans ce guide **ultime** pour maîtriser l’art d’allumer ton ordinateur, lancer une recherche Google, et atterrir sur le site de ton choix (ici, on parle de **Pornhub**, mais ça marche pour n’importe quel site). Que tu sois un newbie ou un pro du clavier, ce tuto va te guider avec style ! 😎

---

## 🎯 **Objectif**
- Allumer ton ordinateur.
- Ouvrir un navigateur web.
- Faire une recherche Google.
- Accéder à **Pornhub** (ou tout autre site) en un clin d’œil.

**Temps estimé** : 2 minutes chrono ! ⏱️

---

## 🛠 **Pré-requis**
- Un ordinateur (PC, Mac, Linux, peu importe !).
- Une connexion Internet (Wi-Fi ou câble Ethernet).
- Un clavier, une souris, et un peu de curiosité.
- **Optionnel** : Une boisson énergisante pour l’ambiance. 🥤

---

## 📜 **Étapes pour devenir un ninja du web**

### 1. **Allumer ton ordi comme un boss** 💻
1. **Trouve le bouton Power** :
   - Sur un PC portable, c’est souvent un bouton au-dessus du clavier ou sur le côté.
   - Sur un PC de bureau, check la tour (généralement un gros bouton avec un symbole ⏻).
2. **Appuie dessus** : Un petit *bip* ou une lumière devrait s’allumer. Si rien ne se passe, vérifie que l’ordi est branché ou que la batterie n’est pas à plat. 🔌
3. **Attends le démarrage** : Ton écran va afficher un logo (Windows, Apple, ou autre). Si t’as un mot de passe, entre-le pour te connecter.

> **Astuce pro** : Si ton PC est lent à démarrer, fais-toi un café en attendant. ☕

---

### 2. **Ouvrir un navigateur web** 🌍
1. Une fois sur ton bureau, trouve un **navigateur** :
   - **Google Chrome** (icône ronde multicolore).
   - **Firefox** (icône avec un renard).
   - **Safari** (icône de boussole, pour les Mac users).
   - **Edge** (icône bleue en vague, si t’es sur Windows).
2. **Double-clique** sur l’icône ou cherche le navigateur dans le menu Démarrer (Windows) ou le Dock (Mac).
3. Le navigateur s’ouvre ? T’es déjà à mi-chemin ! 🎉

> **Fun fact** : Tu peux aussi taper le nom du navigateur dans la barre de recherche de ton ordi (Windows : touche Windows + S ; Mac : Cmd + Espace).

---

### 3. **Faire une recherche Google** 🔍
1. Dans la barre d’adresse (en haut du navigateur), tape : `www.google.com` et appuie sur **Entrée**.
2. Sur la page Google, clique dans la barre de recherche au centre.
3. Tape : `Pornhub` (ou le nom du site que tu veux).
4. Appuie sur **Entrée** ou clique sur le bouton 🔍 **Rechercher avec Google**.

> **Conseil de pro** : Si tu veux aller plus vite, tape directement `pornhub.com` dans la barre d’adresse et zou !

---

### 4. **Accéder à Pornhub** 🎥
1. Dans les résultats Google, le premier lien est généralement **www.pornhub.com**. Clique dessus.
2. Tada ! Tu devrais arriver sur la page d’accueil de Pornhub.
3. **Note** : Si tu as un bloqueur de contenu ou un contrôle parental, il se peut que le site ne s’ouvre pas. Dans ce cas, contacte ton administrateur réseau (ou passe en navigation privée, mais chut 🤫).

> **Mode ninja** : Ouvre une fenêtre de navigation privée (Ctrl + Shift + N sur Chrome/Firefox, ou Cmd + Shift + N sur Safari) pour éviter que ta recherche reste dans l’historique.

---

## ⚠️ **Points importants**
- **Âge légal** : Pornhub est un site pour adultes. Assure-toi d’avoir l’âge requis (18+ dans la plupart des pays).
- **Sécurité** : Utilise une connexion sécurisée et évite de partager des infos personnelles.
- **Respect des lois** : Vérifie que l’accès à ce site est légal dans ton pays/région.

## 🛠 **Dépannage**
- **L’ordi ne s’allume pas ?** Vérifie la prise, la batterie, ou appelle un pote geek.
- **Google ne charge pas ?** Vérifie ta connexion Internet (redémarre ton routeur si besoin).
- **Le site ne s’ouvre pas ?** Essaie un autre navigateur ou désactive temporairement ton bloqueur de pub.
